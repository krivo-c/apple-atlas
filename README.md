# ApplePrice Atlas

Comparateur mondial indépendant des prix Apple.

## Site

Le projet est conçu pour être servi gratuitement par GitHub Pages.

## Données

Un workflow GitHub Actions tente d'actualiser les prix Apple toutes les 6 heures depuis les storefronts nationaux détectés sur Apple.com.

Les taux de conversion affichés dans l'interface sont indicatifs et les prix/taxes peuvent varier selon le marché.

Projet indépendant, non affilié à Apple Inc.
